# 10 — Architecture & folder structure

## Tree
```
app/                              # Expo Router — routes only (thin screens)
  _layout.tsx                     # providers: QueryClientProvider, focusManager, onlineManager, session bootstrap, session expiry listener
  (auth)/login.tsx  register.tsx  forgot-password.tsx
  (tabs)/_layout.tsx              # tabs: Khám phá · Học tập · (Giảng viên) · Tài khoản
  (tabs)/index.tsx                # Khám phá (catalog)
  (tabs)/my-learning.tsx          # Học tập (paginated enrollments)
  (tabs)/instructor.tsx           # Giảng viên (hidden unless D-M01; 5 sections via segmented control)
  (tabs)/account.tsx              # Tài khoản & bảo mật
  courses/[slug]/index.tsx        # course page + CTA (buy on web / free enroll / open learning)
  courses/[slug]/reviews.tsx  write-review.tsx
  courses/[slug]/preview/[lessonId].tsx
  learn/[courseId]/index.tsx      # outline + progress + quizzes web handoff
  learn/lesson/[lessonId].tsx     # player / article, prev/next, visit, manual completion
  learn/[courseId]/qa.tsx         # course Q&A list + create
  learn/qa/[questionId].tsx       # Q&A thread + replies + resolve/delete
  account/certificates.tsx  profile.tsx  change-password.tsx
  instructor/courses/[courseId]/students.tsx
  instructor/entries.tsx  instructor/payout-account.tsx
  instructor/withdrawals/index.tsx  instructor/withdrawals/new.tsx
src/
  config/env.ts                   # EXPO_PUBLIC_* only + dev localhost warning on native
  api/client.ts                   # the ONE axios instance + epoch-guarded refresh
  api/envelope.ts                 # unwrap<T>(body) & Page<T>
  api/tokens.ts                   # platform adapter: SecureStore (native) / memory (web)
  api/problem.ts                  # v2 error envelope → AppError
  api/schema.d.ts                 # GENERATED by openapi-typescript from docs/ai/openapi.json — never edit by hand
  api/query-keys.ts               # every TanStack Query key in one place
  features/<feature>/api.ts       # typed fetchers (call client + unwrap)
  features/<feature>/hooks.ts     # useQuery / useInfiniteQuery / useMutation wrappers
  features/<feature>/logic.ts     # pure business helpers (testable, no React)
  features/<feature>/components/  # feature UI
  components/ui/                  # Button, Text, Screen, EmptyState, ErrorState, Loading, MoneyText …
  hooks/useForegroundSync.ts      # invalidate learning, certificates, earnings, instructor, auth.me on active
  hooks/useRefetchOnScreenFocus.ts# refetch on screen focus (skips initial mount)
  lib/dialog.ts                   # cross-platform confirm & notify (NEVER call Alert.alert outside this file)
  lib/money.ts  lib/date.ts  lib/web-links.ts
  store/session.ts                # Zustand: status ('idle'|'loading'|'authenticated'|'unauthenticated'|'offline'), sessionEpoch, me, accessToken, onSessionExpired
```
Features: `auth`, `profile`, `catalog`, `learning`, `qa`, `reviews`, `certificates`, `instructor`.
Do not create `utils/`, `helpers/`, `common/`, `services/` folders. Shared helpers go to `src/lib/`, shared UI to `src/components/ui/`.

## Layering (allowed calls)
```
app/ screen ──► features/*/hooks ──► features/*/api ──► src/api/client + envelope
     └──► features/*/components, components/ui, lib/dialog   features/*/logic (pure) ◄── anyone
```
Forbidden: a screen or component importing `src/api/client` or axios; a feature importing another feature's
`api.ts` (use its hooks, or move the shared piece to `src/lib`); business logic inside `app/`.

## State
- **Server state = TanStack Query only.** Keys come from `src/api/query-keys.ts`.
  After a mutation, invalidate what it changes (e.g., completion → `['learning']`, `['certificates']`; withdrawal → `['earnings']`, `['instructor']`; Q&A answer/resolve → `['qa']`, `['instructor']`).
- **Refetch on screen focus** (via `useRefetchOnScreenFocus`) for: Học tập, Phòng học, Chứng chỉ, Giảng viên.
- **Client state = Zustand `session` store only** (`status`, `sessionEpoch`, `me`, `accessToken` in memory). No other global store. Form state lives in `react-hook-form`.
- Never persist server data to AsyncStorage. Never store tokens in `localStorage` or AsyncStorage.

## Navigation rules
- 401 that cannot be refreshed / session expired → `clearSession()` + `queryClient.clear()` → `router.replace('/(auth)/login')`.
- 403 `NOT_ENROLLED` on a learning screen → navigate back to the course page with notice.
- Opening the website: `WebBrowser.openBrowserAsync(webLinks.x())` via `expo-web-browser`.
