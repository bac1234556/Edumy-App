# 10 — Architecture & folder structure

## Tree
```
app/                              # Expo Router — routes only (thin screens)
  _layout.tsx                     # providers: QueryClientProvider, session bootstrap, theme
  (auth)/login.tsx  register.tsx  forgot-password.tsx
  (tabs)/_layout.tsx              # tabs: Khám phá · Học tập · Giỏ hàng · Tài khoản · (Giảng viên, D-M01)
  (tabs)/index.tsx                # Khám phá (catalog)
  (tabs)/my-learning.tsx
  (tabs)/cart.tsx
  (tabs)/account.tsx
  (tabs)/instructor.tsx           # hidden unless D-M01
  courses/[slug]/index.tsx        # course page + action (D-M02)
  courses/[slug]/reviews.tsx
  courses/[slug]/preview/[lessonId].tsx
  learn/[courseId]/index.tsx      # outline + progress
  learn/lesson/[lessonId].tsx     # player / article, completion toggle
  learn/[courseId]/questions/index.tsx  questions/[id].tsx  questions/new.tsx
  orders/index.tsx  orders/[orderCode].tsx
  certificates/index.tsx
  account/profile.tsx  account/change-password.tsx
  instructor/earnings.tsx  instructor/entries.tsx  instructor/payout-account.tsx
  instructor/withdrawals/index.tsx  instructor/withdrawals/new.tsx
src/
  config/env.ts                   # EXPO_PUBLIC_* only
  api/client.ts                   # the ONE axios instance + interceptors
  api/tokens.ts                   # secure-store refresh token, in-memory access token
  api/problem.ts                  # ProblemDetail → AppError
  api/schema.d.ts                 # GENERATED by openapi-typescript — never edit by hand
  api/query-keys.ts               # every TanStack Query key in one place
  features/<feature>/api.ts       # typed fetchers (call client)
  features/<feature>/hooks.ts     # useQuery / useMutation wrappers
  features/<feature>/logic.ts     # pure business helpers (testable, no React)
  features/<feature>/components/  # feature UI
  components/ui/                  # Button, Text, Screen, EmptyState, ErrorState, Loading, MoneyText …
  lib/money.ts  lib/date.ts  lib/web-links.ts
  store/session.ts                # Zustand: status, me, accessToken (memory only)
```
Features: `auth`, `profile`, `catalog`, `cart`, `orders`, `learning`, `qa`, `reviews`, `certificates`, `earnings`, `withdrawals`.
Do not create `utils/`, `helpers/`, `common/`, `services/` folders. Shared helpers go to `src/lib/`, shared UI to `src/components/ui/`.

## Layering (allowed calls)
```
app/ screen ──► features/*/hooks ──► features/*/api ──► src/api/client
     └──► features/*/components, components/ui        features/*/logic (pure) ◄── anyone
```
Forbidden: a screen or component importing `src/api/client` or axios; a feature importing another feature's
`api.ts` (use its hooks, or move the shared piece to `src/lib`); business logic inside `app/`.

## State
- **Server state = TanStack Query only.** Keys come from `src/api/query-keys.ts`.
  After a mutation, invalidate what it changes (examples: add to cart → `cart`, `courseDetail(slug)`;
  completion → `outline(courseId)`, `enrollments`; withdrawal → `earningsSummary`, `withdrawals`).
- Refetch on screen focus for: My learning, Cart, Orders, Earnings (the user may have acted on the web).
- **Client state = Zustand `session` store only** (status `unknown|anonymous|authenticated`, `me`, access token in memory).
  No other global store. Form state lives in react-hook-form.
- Never persist server data to AsyncStorage. Never store tokens in AsyncStorage.

## Navigation rules
- 401 that cannot be refreshed → clear session → `router.replace('/(auth)/login')`.
- 403 `ENROLLMENT_REQUIRED` on a learning screen → go to `courses/[slug]`.
- Opening the website (UC-M01): `Linking.openURL(webLinks.x())` (system browser, keeps the user's web session).
