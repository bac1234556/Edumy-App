01. RAM-ONLY ACCESS TOKEN

Zustand In-Memory Store

02. HARDWARE KEYSTORE

Expo SecureStore

Opaque Refresh Token lưu độc quyền tại edumy.refreshToken được mã hóa bằng iOS Keychain / Android Keystore.

03. TOKEN ROTATION

Reuse Detection

Mỗi lần gọi /auth/mobile/refresh sinh token mới và hủy token cũ. Nếu token cũ bị dùng lại, Server khóa ngay cả họ phiên (Family).
